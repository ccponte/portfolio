Featured Project: GoodChain

GoodChain is a smart donation distribution platform designed to connect donors, beneficiaries, and pickup locations through a transparent and secure workflow. The project addresses a real-world social challenge: improving the coordination, traceability, and prioritization of donation requests while protecting user data and supporting role-specific responsibilities.

Problem and Solution

Many donation initiatives depend on informal communication channels, which can make prioritization, accountability, and pickup coordination difficult. GoodChain introduces a structured web-based platform where beneficiaries can register needs, donors can commit donations through a simulated payment authorization flow, pickup locations can validate collection codes, and administrators can manage users and records.

Technical Implementation

The solution was implemented using Java, Spring Boot, Thymeleaf, Bootstrap, PostgreSQL, Spring Security, Docker, GitHub Actions, JUnit, MockMvc, and k6. The application includes authentication, role-based authorization, administrative controls, automated tests, and deployment-oriented configuration.
